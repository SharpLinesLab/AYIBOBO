# Translations: Kreyòl, Français, English

## How it works
- **Where strings live:** `src/i18n/locales/{en,fr,ht}/<namespace>.ts`. English is the source of truth.
  - The French and Kreyòl files are typed against the English one, so **the build fails if a key is missing**.
  - The namespaces are `common`, `browse`, `pages` and `player`.
- **Keys:** `namespace.area.name`, for example `pages.song.lyrics`.
- **Placeholders:** `{name}` inside a string is filled by `t('key', { name })`.
- **Plurals:** pairs of keys, `x_one` and `x_other`, chosen by `plural('ns.x', n)`.
  - `{n}` is formatted automatically.
  - French treats 0 and 1 as singular.
  - Kreyòl nouns don't change, so both forms are usually identical.
- **In code:**
  - `import { t, plural, fmtDate, fmtNumber, fmtRelative } from '../i18n'`.
  - `compact()`, `relativeTime()`, `usd()` and `num()` already follow the current language.
  - Never call `toLocaleDateString('en-US')` directly; use `fmtDate`.
- **Switching language:** the whole interface re-renders; playback continues.
- **Loading:** French and Kreyòl load on demand.

## What we translate, and what we don't
- **Translate:** all interface copy. That includes headings, buttons, labels, `aria-label`s, placeholders, `alt` text, toasts, `confirm()` prompts, empty states, page titles and genre names.
- **Never translate:** artist names, song, album and playlist titles, lyrics, user comments, artist bios, and the demo catalog's descriptions. These are content, not interface.
- **Brand names stay as they are:** ASF and Ayiti Sakap Fet.

## Style
**Kreyòl**
- Use standard orthography (IPN): `è`, `ò` and `en`/`an`/`on`, with no silent letters.
- Write natural spoken Kreyòl rather than word-for-word French.
- Use short forms where natural: *ou → w*, *li → l*, *mwen → m*.
- Plurals use `yo` only where needed.
- Address the listener as *ou*.

**Français**
- Address the listener as *vous*.
- Use the vocabulary listeners know from big streaming apps (*titre, écoutes, abonnés, Titres aimés*).
- Follow French typography: a non-breaking space before `: ; ! ?`, and « guillemets ».

**General**
- Keep strings short. French and Kreyòl run 20–30 % longer than English, so check buttons and tabs on phones.
