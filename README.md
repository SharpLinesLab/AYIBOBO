# ASF — Ayiti Sakap Fet Music

A premium music streaming and discovery platform for Haiti and the diaspora, in the spirit of Audiomack. It has full-length songs, charts, genres, artist, album and playlist pages, a personal library and uploads.

## Streaming app

- **Discover:**
  - A cinematic featured-release carousel with blurred-artwork backdrops.
  - Genre tiles.
  - Shelves for Jump back in, Trending now, Top songs this week, New releases, Made for you, Featured playlists and Artists to watch.
- **Browse pages:**
  - **Trending:** songs ranked by week-over-week growth, with genre filters.
  - **Top Charts:** songs or albums for today, this week, this month or this year, with ▲▼/NEW movement.
  - **Genres:** 13 genres, from kompa, rap kreyòl, afrobeats and amapiano to drill, zouk, rara and gospel.
- **Detail pages:**
  - **Song:** a scrubbable waveform; play, like and repost buttons; timestamped comments (pinned on the waveform); more from the artist; and similar songs.
  - **Album and playlist:** play, shuffle play, and save or follow.
  - **Artist:** a banner, follow, popular songs, releases, appears-on and fans-also-like.
- **Player:**
  - A persistent glass player bar with queue, shuffle, repeat (off / all / one), volume and a sleep timer.
  - A full-screen **Now Playing** view with a live frequency visualizer, the waveform and the queue.
  - Media Session support for lock-screen and hardware keys.
  - Keyboard shortcuts: Space play/pause, ←/→ seek, Shift+←/→ previous/next, M mute, `/` search.
- **Library:** liked songs, your playlists ("⋯ → Add to playlist" on any song), followed artists, recently played, and your uploads.
- **Search:** grouped, accent-insensitive results as you type, across songs, artists, albums and playlists.
- **Upload:**
  - Drag in an MP3, WAV, M4A or OGG file; it's decoded in the browser to build the waveform.
  - Design generative cover art.
  - Publish with your artist name. The audio is stored in IndexedDB.
- **Audio without assets:**
  - Every catalog song is synthesized live with the Web Audio API from a recipe (genre, BPM, key, seed).
  - Bars are rendered on demand with genre-specific drums, bass, chords and lead, in an intro / verse / hook / break / outro structure. So songs stream from any position with almost no memory.
  - Artwork is generative SVG.
- **Look and feel:** a dark premium theme by default with the ASF green accent, plus a light theme, responsive layouts, and a sidebar on desktop or bottom tabs with a mini-player on mobile.

The demo catalog (18 artists, ~100 songs, albums, editorial playlists) is **fictional**. Library data (likes, playlists, follows, comments, uploads) is stored per browser.

## Artwork

- **Generated by default.** Every artist gets editorial imagery: stage-lit, rim-lit silhouettes with haze, bokeh and film grain, as a poster (3:4), a portrait and a wide stage banner. Lead releases use photo-style covers built from that imagery, and other releases use generative editorial designs.
- **Use real artwork by dropping files in.** Put licensed images in `src/assets/artwork/` and they're picked up automatically at build time. They replace the generated art everywhere: avatars, posters, banners, covers, the player, the lock screen and genre tiles. The naming is in [`src/assets/artwork/README.md`](src/assets/artwork/README.md), e.g. `artists/ar-tiga-blaze.jpg`, `artists/ar-tiga-blaze-banner.jpg`, `releases/al-tiga-blaze-1.jpg`.
- **Uploads can carry real covers.** Creators can attach their own cover image (JPG, PNG, WebP or AVIF, up to 8 MB) when they upload a song.

Only publish images you own or have a licence for.

## Quick start

```bash
npm install
npm run dev          # the whole app at http://localhost:5173 (everything runs in the browser)
npm test             # catalog, charts, search, lyrics and API tests
npm run test:e2e     # build, then Playwright + axe in English, French and Kreyòl
```

Production server (serves the built app, the newsletter API and the security headers):

```bash
cp .env.example .env            # see the file for every setting
npm run build
npm start                       # http://localhost:8787
```

Develop against the API with hot reload: `npm run dev:server` in one terminal, then `API_PROXY=http://localhost:8787 npm run dev`.

Docker: `docker build -t asf . && docker run -p 8787:8787 -v asf-data:/data asf`

The music app needs no server: on static hosting the newsletter sign-up is kept in the browser instead.

## Branding

Brand name, contact email and social profile URLs live in `src/brand.ts`. Social icons link to each platform's home page until you fill in your profile URLs. Colors are CSS tokens at the top of `src/styles/app.css` (dark by default, with a light theme toggle).

## Payments

There are no payments in the app yet. Local Haitian payment methods (MonCash, Natcash) are planned as a separate feature.

## API

| Method | Path | |
|---|---|---|
| GET | `/api/health` | `{ ok: true }` |
| POST | `/api/newsletter` | `{email}` (Subscribe button) |
| POST | `/api/newsletter/unsubscribe` | `{email}` (always answers `{ ok: true }`) |

Server hardening:

- A strict Content-Security-Policy (no inline scripts), `nosniff`, `X-Frame-Options: DENY` and a strict referrer policy.
- Per-IP rate limits on every POST (`RATE_LIMIT_MULTIPLIER` scales them for load tests).
- 32 KB JSON body cap.
- The Docker image runs as a non-root user and has a health check.

## Project layout

```
src/catalog/    music catalog: seed, generative covers, play history & charts, search, uploads (IndexedDB)
src/player/     audio engine (queue, transport, Media Session) and genre synthesizer
src/pages/      streaming pages (Discover, Browse, Detail, Library/Search/Upload)
src/music.tsx   catalog + library context and player hooks
src/lib/        small shared helpers (seeded random, newsletter, time formatting)
src/components/ UI components (shell/ and music/)
src/i18n/       English, French and Kreyòl translations
server/         Express server: static app, security headers, newsletter API, JSON datastore
tests/          vitest suites
```

## Production notes

- The JSON datastore is meant for a single instance. For horizontal scaling, move `server/db.ts` to Postgres or SQLite behind the same interface.
- Run behind TLS. `trust proxy` is enabled for correct client IPs.
